# THADAM AI 🛡️
**Every attack leaves a trail. We follow it.**

Agentic cybersecurity investigation MVP combining event correlation, security-knowledge retrieval (RAG), specialist-agent reasoning, MITRE ATT&CK mapping, attack-chain reconstruction, self-challenge reasoning and human-gated response recommendations.

## Run
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Click **Run Demo Investigation**, then **Challenge My Verdict**.

This is a hackathon MVP. Response actions are recommendations/simulations and require human approval.
